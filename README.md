# Zolmyra AI OS

Actúa como un Senior Product Designer, UX Architect, SaaS Architect y Frontend Engineer especializado en CRM, Inteligencia Artificial, WhatsApp Business, HubSpot, Salesforce y plataformas empresariales modernas.

Tu misión es diseñar visualmente y generar la interfaz completa de una plataforma llamada:

ZOLMYRA AI OS

Slogan:

"Convierte conversaciones en oportunidades mediante Inteligencia Artificial."

Objetivo:

Crear una plataforma moderna donde pueda controlar clientes, conversaciones, oportunidades, automatizaciones, agentes IA y seguimiento comercial desde una única pantalla.

La interfaz debe ser moderna, profesional, elegante, limpia y de nivel empresarial.

Inspirarse en:

- HubSpot

- Salesforce

- Monday

- Zoho CRM

- Notion

- Microsoft Dynamics 365

- Linear

- ClickUp

Diseña un SaaS Dashboard completo con las siguientes áreas:

# Dashboard Ejecutivo

Widgets:

- Leads del día

- Conversaciones activas

- Oportunidades abiertas

- Ventas potenciales

- Seguimientos pendientes

- Clientes activos

- Tasa de conversión

- Ingresos proyectados

Mostrar:

- Gráficos de barras

- Embudo comercial

- Tendencias

- KPIs

# Contactos

Tabla profesional con:

- Nombre

- Empresa

- Teléfono

- Correo

- Estado

- Fuente

- Fecha de creación

- Última actividad

Funciones:

- Buscar

- Filtrar

- Editar

- Crear contacto

# Leads

Pipeline tipo Kanban:

- Nuevo

- Contactado

- Calificado

- Propuesta

- Negociación

- Ganado

- Perdido

Permitir:

- Arrastrar tarjetas

- Ver detalles

- Asignar responsable

# Conversaciones WhatsApp

Diseñar interfaz estilo:

- WhatsApp Web

- HubSpot Inbox

Panel izquierdo:

- Lista de conversaciones

Panel central:

- Chat completo

Panel derecho:

- Información del cliente

- Estado del lead

- Historial

- Notas IA

# Inteligencia Artificial

Página dedicada para el agente IA.

Mostrar:

- Resumen ejecutivo de clientes

- Detección de intención

- Lead Scoring

- Recomendaciones de seguimiento

- Próximas acciones sugeridas

Ejemplos:

"Este cliente tiene una probabilidad de cierre del 85%"

"Recomendamos contactar en 24 horas"

# Automatizaciones

Vista visual tipo N8N.

Permitir visualizar:

- Webhooks

- APIs

- Flujos

- Seguimientos automáticos

Mostrar bloques conectados.

# Oportunidades

Tabla avanzada con:

- Cliente

- Producto

- Valor estimado

- Probabilidad

- Estado

- Fecha estimada de cierre

# Reportes

Mostrar:

- Conversión

- Rendimiento

- Leads por origen

- Ventas por periodo

- Seguimientos realizados

Secciones:

- Integraciones

Estilo:

- Sombras suaves

- Componentes modernos
